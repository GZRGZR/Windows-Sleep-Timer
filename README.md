# Windows Sleep Timer

כלי קטן ל-Windows שמציג ממשק בעברית ומכניס את המחשב למצב שינה או מכבה אותו בתום טיימר.

## הפעלה

1. הורידו את הפרויקט כ-ZIP וחלצו את הקבצים.
2. השאירו את שני הקבצים באותה תיקייה:
   - Start-Sleep-Timer.bat
   - Sleep-Timer-GUI.ps1
3. לחצו פעמיים על Start-Sleep-Timer.bat.
4. בחרו פעולה בסיום: שינה (ברירת מחדל) או כיבוי. הזינו את משך הזמן ולחצו על "התחל טיימר". חלון התוכנה נשאר פתוח ומציג ספירה לאחור.

אין צורך בהתקנה, בהרשאות מנהל או בחיבור לאינטרנט. הכלי משתמש ב-Windows PowerShell ובספריות WinForms המובנות ב-Windows.

## פורמט הזנת הזמן

- 10 = 10 דקות.
- 3.4 = 3 דקות ו-40 שניות.
- 3.45 = 3 דקות ו-45 שניות.
- 3.59 = 3 דקות ו-59 שניות.
- 3.6 = 3 דקות ו-36 שניות.
- 3.75 = 3 דקות ו-45 שניות.

כלל ההבחנה: סיומת עד 0.59 מפורשת כשניות בפורמט דקות.שניות; סיומת מעל 0.59 מפורשת כחלקי דקה. אפשר להשתמש בנקודה או בפסיק.

## אפשרויות

- ברירת המחדל היא מצב שינה. אפשר לבחור במקום זאת כיבוי.
- ליד בחירת הכיבוי מוצגת אזהרה: כיבוי עלול לסגור תוכנות ולגרום לאובדן נתונים שלא נשמרו. פקודת הכיבוי אינה משתמשת במתג force, אך יש לשמור מסמכים לפני כן.
- במהלך הטיימר, לחיצה ימנית על חלון הספירה פותחת תפריט משני עם האפשרות "חזרה לבחירת זמן". בחירה בה דורשת אישור נוסף ומבטלת את הטיימר הנוכחי; אין כפתור גלוי שעלול להילחץ בטעות.
- חלון ספירה לאחור קטן וקומפקטי; הוא אינו מכסה את המסך.
- אפשרות להעלות את החלון הקטן מעל שאר החלונות בשלב הסיום; לאחר הארכה הוא נשאר עליון עד 40 שניות לכל היותר.
- צליל התראה ב-30 השניות האחרונות.
- כפתור "הוסף 20 שניות" להארכת הטיימר.
- ברגע שנכנסים ל-20 השניות האחרונות, ניתן להוסיף 20 שניות רק כשנותרו 20 שניות או פחות. כך הזמן שנותר בשלב הסיום לא יצטבר מעל 40 שניות; לאחר תוספת הכפתור ימתין עד שהספירה תרד שוב ל-20 שניות.
- מוצגים משך הזמן המקורי שהוגדר ומספר הפעמים שבהן נוספו 20 שניות.
- כפתור לביטול הטיימר.

## הערות

- ברירת המחדל היא מצב שינה (Sleep). במצב כיבוי Windows מקבל בקשת כיבוי רגילה, ללא כפיית סגירה של תוכנות.
- מחשב עשוי להתעורר שוב ממקש, עכבר, כפתור הפעלה או התקן שהוגדר להעיר אותו. הסקריפט אינו נועל את אפשרות ההתעוררות.
- אחרי שהמחשב מתעורר ממצב השינה, התוכנה נסגרת אוטומטית.
- מומלץ לבדוק תחילה טיימר קצר ולוודא שמצב השינה פועל במחשב.
